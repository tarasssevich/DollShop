# 🤖 Настройка Telegram-бота уведомлений для мастера (DollShop)

Этот документ описывает, как подключить Telegram-бота для мгновенного получения уведомлений о новых заказах и заявках «Хочу похожую» с интерактивными кнопками подтверждения и отмены (Step 5.3).

---

## 1. Создание Telegram-бота через @BotFather

1. Откройте в Telegram официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Введите название бота (например, `DollShop Уведомления`).
4. Введите юзернейм бота, заканчивающийся на `bot` (например, `DollShop_Orders_Bot`).
5. Скопируйте полученный **HTTP API Token** (формата `1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

---

## 2. Получение вашего Telegram Chat ID

1. Откройте вашего созданного бота и нажмите кнопку **«Запустить»** (`/start`).
2. Чтобы узнать ваш персональный `chat_id`:
   - Напишите любому проверенному боту (например, [@userinfobot](https://t.me/userinfobot)) — он пришлет ваш `Id`.
   - Либо откройте в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` и найдите поле `"chat":{"id": 123456789}`.

---

## 3. Настройка переменных окружения

В файле `.env.local` укажите:

```env
TELEGRAM_BOT_TOKEN="1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ"
TELEGRAM_CHAT_ID="123456789"
TELEGRAM_WEBHOOK_SECRET="любая_секретная_строка_для_защиты"
```

> **Примечание:** Если эти переменные не заданы (например, на локальном компьютере при разработке), система автоматически работает в режиме безопасного офлайн-фоллбека — заказы и заявки оформляются штатно, а текст сообщений выводится в лог терминала.

---

## 4. Обработка интерактивных кнопок Telegram

Кнопки **«✅ Подтвердить продажу»** и **«❌ Отменить бронь»** поддерживают два режима работы:

### Режим А: Локальная разработка и тестирование (Long Polling)
Не требует наличия публичного домена, белого IP или настройки туннелей. Просто запустите во втором терминале:

```bash
npm run tg:poll
```

Воркер подключается к вашему Telegram боту, мгновенно считывает нажатия на кнопки и передает их в локальное приложение `http://localhost:3001/api/telegram/webhook`. Статус куклы и заказа обновляется прямо в базе данных, а сообщение в Telegram меняется на подтвержденное/отмененное.

### Режим Б: Продакшен (Webhooks)
Когда сайт развернут на боевом сервере с доменным именем и HTTPS (например, `https://dollshop.by`):

Отправьте GET-запрос в браузере или через curl:
```
https://api.telegram.org/bot<ВАШ_ТОКЕН>/setWebhook?url=https://<ВАШ_ДОМЕН>/api/telegram/webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>
```

### Как работают интерактивные кнопки:
- **«✅ Подтвердить продажу»**: вызывает атомарную процедуру `set_order_status(order_id, 'paid')`. Кукла автоматически переводится в статус `sold` («В частной коллекции» / Галерея), сбрасывается ISR-кэш витрины, а в Telegram отображается статус подтверждения.
- **«❌ Отменить бронь»**: вызывает процедуру `set_order_status(order_id, 'cancelled')`. Бронь куклы снимается, и она немедленно возвращается в каталог в статус `available` («🟢 Ищет дом»).
- **«🔗 Открыть заказ в админке»**: прямая ссылка на админ-панель для просмотра адреса и деталей.
